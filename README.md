# خودرو | خرید، فروش و حواله خودرو
وب‌سایت فارسی و راست‌چین برای معرفی خودروهای بازار ایران، ثبت درخواست خرید و فروش و پیگیری فرصت‌های حواله.

## ساختار
- `index.html`: صفحه نخست
- `pages/buy.html`: خرید خودرو
- `pages/sell.html`: فروش خودرو
- `pages/bank.html`: بانک خودرو
- `pages/transfers.html`: خرید و فروش حواله
- `pages/guide.html`: راهنمای معامله
- `pages/contact.html`: تماس
- `assets/css/style.css`: طراحی مشترک
- `assets/js/app.js`: جست‌وجو، فیلتر و تعاملات
- `assets/images/`: تصاویر پروژه

## انتشار
در تنظیمات مخزن، GitHub Pages را روی شاخه `main` و پوشه `/(root)` تنظیم کنید.

## نکته
اطلاعات خودروهای نمونه صرفاً نمونه نمایشی هستند؛ پیش از انتشار نهایی باید قیمت، موجودی، وضعیت حواله و مشخصات فروشنده با اطلاعات واقعی جایگزین شوند.
